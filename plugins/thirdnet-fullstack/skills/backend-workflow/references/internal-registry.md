# 内部源地址（NuGet / npm）

ThirdNet 模板与脚手架依赖内部 NuGet / npm 源。本文件是**唯一地址源**——各技能正文不得重复罗列地址，统一引用此处。

## NuGet 源（后端模板 / 包）

| 网络 | 地址 | 用途 |
|------|------|------|
| 内网（默认） | `http://192.168.1.156:8088/nuget` | 模板安装、包还原 |
| 外网（内网不可达时） | `http://61.164.57.61:8088/nuget` | 同上 |

一次性配置：`dotnet nuget add source http://192.168.1.156:8088/nuget -n ThirdNet`（外网同理）。

## npm 源（前端脚手架 `create-thirdnet-admin`）

| 网络 | 地址 | 用途 |
|------|------|------|
| 内网（默认） | `http://192.168.1.207:4873/` | `create-thirdnet-admin` 安装 |
| 外网（内网不可达时） | `http://61.164.57.61:14873/` | 同上 |

> ⚠️ **端口差异**：外网 npm 端口是 **14873**（不是内网的 4873）。内网用 4873、外网用 14873，二者不要混用。

## 选择规则

1. 默认用内网地址。
2. 内网不可达（超时 / 拒绝连接）时切外网地址。
3. 切换后无需改动代码，仅替换命令中的 registry 参数。
