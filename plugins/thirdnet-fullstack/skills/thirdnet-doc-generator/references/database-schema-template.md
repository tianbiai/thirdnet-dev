## 1. 文档说明

- **定位**：技术参考（与 `spec.md` 同类），面向开发 / DBA / 运维 / 接手者。
- **数据源**：经 dbhub MCP 实时导出于 `[库名]`；表 / 字段 / 类型 / 注释均来自线上库，注释即 PostgreSQL `COMMENT`（后端 `EntityConfiguration.HasComment()` 写入）。
- **「注释」与「备注」分工**：
  - **注释** = 数据库 `COMMENT`（业务中文说明，权威）。
  - **备注** = 结构元数据（主键 / 可空 / 默认值 / 唯一）+ 语义标注（审计字段 / 枚举字典）。其中「（推断）」项为按命名启发式得出，需人工核对。
- **乐观锁**：thirdnet 表默认启用 `xmin` 乐观并发列（PostgreSQL 系统列，每表皆有，非业务字段），字段表不单独展开。
- **缺失注释**：表 / 列未设 `COMMENT` 者标 `[未设置注释]`，必要时附「（推断：…）」并汇总于第 5 节。
